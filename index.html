Setup tips

  1. Open the booth from its https link (not a downloaded file). The camera needs a secure page.
  2. Add it to the Home Screen so photos are better protected and it opens like an app.
    • iPad: Share button → Add to Home Screen.
    • Android: browser menu → Add to Home Screen or Install app.
  3. During the event, lock the tablet to this app so guests cannot leave it.
    • iPad Guided Access: Settings → Accessibility → Guided Access, turn it on, then triple-click the side (or Home) button to start. Set a passcode you remember.
    • Android app pinning: Settings → Security → App pinning (wording varies). Pin the SALIN booth, then use your PIN or fingerprint to unpin.
  4. Never use a private or incognito tab. Photos may disappear when the tab closes.
  5. Never clear this browser's data or “website data” before you have exported the photos.
  6. At the end of the event, open Host admin (press and hold the logo) and tap Export all (backup so far). Keep that ZIP in a safe place. If Cloud backup is on, also check that the Drive count matches.
