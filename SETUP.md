# Setup tips for the SALIN souvenir booth

Read this once before an event. These steps keep guest photos safe on the one tablet that runs the booth.

## 1. Open the https link

Open the booth from its **https** address in Safari (iPad) or Chrome (Android). Do not open a downloaded file. The camera only works on a secure page.

## 2. Add to Home Screen

This helps the tablet keep the photos and makes the booth open like an app.

- **iPad (Safari):** tap the **Share** button, then tap **Add to Home Screen**. Open the booth from that icon from now on.
- **Android (Chrome):** tap the menu, then **Add to Home Screen** or **Install app**. Open it from the icon.

After this, Host admin should say **Photos protected ✓**. If it still says **Add to Home Screen for best protection**, open the booth from the Home Screen icon and try again.

## 3. Lock the tablet to this app during the event

Guests should not be able to leave the booth by accident.

- **iPad Guided Access:** go to **Settings > Accessibility > Guided Access** and turn it on. Set a passcode you will remember. Open the booth, then **triple-click** the side button (or the Home button) to start Guided Access. Triple-click again and enter the passcode to end it.
- **Android app pinning:** go to **Settings > Security** (wording varies) and turn on **App pinning**. Open the booth, then pin it. You will need your PIN, pattern, or fingerprint to unpin.

## 4. Never use a private or incognito tab

Private tabs can throw photos away when the tab closes. Use a regular Safari or Chrome window, preferably from the Home Screen icon.

## 5. Never clear browser data before you export

Do not clear history, website data, or Safari/Chrome storage until you have exported the photos. That can wipe the board on this tablet. (Photos already copied to Google Drive stay in Drive.)

## 6. Export at the end of the event

1. Press and hold the **SA·LIN logo** for about one second.
2. Enter the host PIN.
3. Tap **Export all (backup so far)** and keep the ZIP in a safe place.
4. If Cloud backup is on, check that the “backed up” count matches the photos on the wall.
5. When you are ready for the next event, tap **Start new event** and follow the steps. The same booth link is reused; only the photos on this tablet are cleared.

## If something looks wrong

- Host admin may show a warning if the booth is in a private tab, if storage is missing, or if space is low. Follow that message before guests start.
- If you see **Last backup: …, 25 since** and a red dot on the export button, export now — many new photos have been taken since the last ZIP.
